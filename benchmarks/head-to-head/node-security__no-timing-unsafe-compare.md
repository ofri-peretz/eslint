## Read this before quoting the numbers

**We wrote this battery.** A score on a set chosen by the rule’s own authors
measures the authors. It is a floor on how we handle cases we thought of, not
a measurement of the rule in the world.

### What we still get wrong

- A BARE name comparison — `if (password === input)` — is silent here and reported by eslint-plugin-security. That is a deliberate inversion, not an oversight: this rule requires one operand to be attacker-reachable. Before the inversion it produced 27 findings on the scanned corpus with zero real oracles among them, so the recall it gives up was recall over noise. The divergence is recorded as decoy cases below rather than left implicit.
- A secret held in a variable with no meaningful name is invisible. This rule reads structure and naming, not taint, by policy — no word list closes the general case.
- The vocabulary is configurable (`secretWords`), which is the escape hatch for a project whose naming we cannot guess.
