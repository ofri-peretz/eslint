## Read this before quoting the numbers

**We wrote this battery.** A score on a set chosen by the rule’s own authors
measures the authors. It is a floor on how we handle cases we thought of, not
a measurement of the rule in the world.

### What we still get wrong

- `execFile`/`spawn` with a caller-chosen argument report CWE-88 (argument injection), not CWE-78. eslint-plugin-security does not model argument injection at all, so it is silent on both — which reads as better precision and is less coverage.
- `execFile('ls', ['--', x])` is silent: `--` terminates option parsing, so the value can no longer be read as a flag.
