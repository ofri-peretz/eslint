# Security plugins → 1.0.0: FP/FN brief

**Goal.** Every security plugin still on 0.x gets an FP/FN pass and then ships as `1.0.0`. A 1.0 claims the plugin's rules are accurate on real code, so the bar is that every known false positive and false negative is fixed, with nothing deferred.

**Where.**

## Method, per plugin

1. **Read** every rule, its tests and its docs.
2. **Find problems two ways.**
   - **Synthetic.** Write realistic snippets of how people really use the library (current major versions, typed and untyped, aliases, wrappers, options in variables), plus unrelated code that shares method names. Run them against the **published** version installed in a scratch dir:
     ```
     npm i eslint@9 typescript-eslint eslint-plugin-<x>-security@latest
     ```
     Use a small `lint.mjs` driver (flat config `files: ['**/*.ts','**/*.tsx','**/*.js','**/*.mjs']`, `cwd: '/'`, absolute file paths).
   - **Real code.** Shallow-clone 2–4 popular OSS repos that use the library and lint every file that imports it with all of the plugin's rules. Triage each finding as a TP or an FP, with the repo, file and line.
3. **Fix test-first.** Add the case, watch it fail on the current rule, fix the rule, watch it pass.
   - A case taken from real code carries `// @found <repo>:<file>:<line>`.
   - Every `FP:`/`FN:` case carries `// @found …` and has a `name:`.
   - Never weaken an existing test. If one encoded a defect, move it and say why in a comment.
4. **Design constraint (binding).**
   - Allowed: AST structure, bounded same-file value following, resolving relative imports from disk (cached, abstain when unreadable), and type info when `parserServices.program` exists (optional, never required).
   - **Never decide from a variable name.** Rename every variable to foo/bar: the bad pattern must still fire and the good one stay silent.
   - Keep each plugin's SDK-evidence gate. The cross-plugin lock is `benchmarks/__tests__/sdk-gate-coverage.lock.test.ts`.
5. **Re-run the real-code scan** until it shows only TPs. Lock each TP as an invalid case.
