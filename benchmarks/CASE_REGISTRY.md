## Each case in full

### ILB-0001 — Prototype pollution through a request-supplied key

A value the caller controls is used directly as a computed key on a write. Setting `__proto__` re-parents the object, which is the whole of CWE-1321. This is the shortest form the bug takes in real code.

```js
function f(o, req) { o[req.query.p] = 1; }
```

- **CWE** CWE-1321
- **CVSS** not scored
- **Occurrences** none recorded — this case is constructed, not observed
- **References** CVE-2019-10744 (**unverified** — carried from memory, not checked against the upstream record)

### ILB-0002 — Prototype pollution through an unguarded merge helper

`for (const k in src) dst[k] = src[k]` over a caller-supplied source is the shape behind the published prototype-pollution advisories in the deep-merge family. The key is never named in the source, so no allowlist can be read off the file.

```js
function merge(dst, src) { for (const k in src) { dst[k] = src[k]; } return dst; }
```

- **CWE** CWE-1321
- **CVSS** not scored
- **Occurrences** none recorded — this case is constructed, not observed

### ILB-0004 — Array append written as a self-indexed length

NOT a defect. `arr.length` is a number, so the key cannot name a prototype slot. Written with `arr` as a PARAMETER on purpose: a locally-constructed array was already cleared by an older path, so `const arr = []` would pass whether or not the fix exists — a case that cannot fail is not evidence.

```js
function push(arr, x) { arr[arr.length] = x; }
```

### ILB-0007 — A merge helper guarded by Object.hasOwn

NOT a defect — it is the documented remediation for ILB-0002. Reporting the fix leaves the user with nothing to do, which is how a rule teaches people to disable it.

### ILB-0008 — A timing-unsafe comparison of a bearer token

`===` on a secret short-circuits at the first differing byte, so response time leaks the shared prefix. Observed guarding five HTTP endpoints in a real deployment.

```js
import crypto from 'node:crypto';
function check(req, secret) { if (req.headers.authorization === secret) { return true; } return false; }
```

- **CWE** CWE-208
