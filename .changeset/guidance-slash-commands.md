The `guidance` preset now lints slash commands (`.claude/commands/**/*.md`, and a plugin's `commands/*.md` beside `.claude-plugin/plugin.json`). A command's description is listed in every session beside the skills', so `guidance-budget` holds its description and body to the skill budgets, and `enforced-rule-in-prose` reads its prose.
