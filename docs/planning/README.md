# `docs/planning/` — Internal Planning & Strategy Docs

Forward-looking internal plans that aren't public roadmaps or research notes:
expansion plans, hardening plans, parity/supremacy strategy, the adoption-PR
campaign, and the head-to-head benchmark methodology vs `eslint-plugin-security`.

These are working documents for maintainers and agents — not user-facing docs
(the Fumadocs site under `apps/docs/` is the public surface) and not OWASP rule
roadmaps (those live in [`../roadmaps/`](../roadmaps/)).
