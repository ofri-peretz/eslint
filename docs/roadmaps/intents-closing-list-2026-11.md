# Intents closing list — November 2026

Audit of every intent under `docs/intents/` against `origin/main` at `930eda74d`
(2026-11-07). Goal: every intent ends `shipped` or `dropped`, with no new gates.
Each criterion was located on main with `git grep`, the named test, script or
workflow, and `gh run list` for scheduled jobs.

Rulings applied:

- Measurements run on schedulers, not as roadmap gates. A criterion that is a
  number to reach is met when a scheduled job measures it.
- No new gates. A criterion that only asks for a new blocking check is dropped
  with that reason.
- Close honestly. `shipped` carries a scoped-down evidence note where the
  delivery was narrower than the wording; `dropped` names what superseded it.

well-defined work left) · **BIG** (multi-PR) · **DROP** (superseded or obsolete).
