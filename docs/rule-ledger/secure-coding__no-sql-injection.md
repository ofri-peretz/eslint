14 asserted case(s). These are the claims; each is only as good as the case.

- INSERT INTO is a statement — `'db.query('INSERT INTO audit (actor) VALUES (' + req.headers.authorization + ')');'`
- a computed request property still attributes — `"db.query('SELECT * FROM logs WHERE ip = ' + req.headers['x-forwarded-for']);"`
- a ctx-rooted request attributes — `'db.query('SELECT * FROM users WHERE id = ' + ctx.params.id);'`
- attribution found on the left operand — `'db.query(req.query.prefix + ' SELECT id FROM users WHERE 1=1');'`
- A relative specifier is not a package. `./pg` must NOT silence this rule: the driver-scoped rules reject relative specifiers too, so treating it as evidence would leave the site owned by nobody. a relative specifier spelling a driver name does not silence the rule — `'import db from './pg';`

- a driver-shaped name that is not a driver package does not silence — `'import { z } from 'pg-lite-not-real';`
- a require of a non-driver package does not silence — `'const express = require('express');`
