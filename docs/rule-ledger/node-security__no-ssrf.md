## Why this rule exists

ESLint Rule: no-ssrf
Detects Server-Side Request Forgery (SSRF) vulnerabilities where
user-controlled URLs are passed to HTTP client functions without validation.

CWE-918: Server-Side Request Forgery (SSRF)
