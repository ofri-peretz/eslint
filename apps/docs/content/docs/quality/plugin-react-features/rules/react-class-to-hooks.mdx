## Rule Details

Identifies React class components that can be migrated to functional components with hooks, providing complexity analysis and migration guidance.

A React class component is a class that extends React's `Component` or
`PureComponent`, however the file names it (`Component`, a renamed import,
`React.Component`, a namespace import), declared, written as a class
expression, or as an anonymous `export default class`. A class extending a
`Component` the file declares itself or imports from another library is not
one.

An **error boundary** (a class with `componentDidCatch` or a static
`getDerivedStateFromError`) is never reported: React has no hooks equivalent,
and documents that an error boundary cannot be written as a function
component.

## Configuration

| Option                       | Type      | Default | Description                                        |
| ---------------------------- | --------- | ------- | -------------------------------------------------- |
| `ignorePureRenderComponents` | `boolean` | `false` | Skip classes that extend `PureComponent`           |
| `allowComplexLifecycle`      | `boolean` | `false` | Skip classes using `getDerivedStateFromProps` or `getSnapshotBeforeUpdate` (no simple hook mapping) |

## Examples

### ❌ Class Component

```typescript
class UserProfile extends React.Component<Props, State> {
  state = {
    loading: false,
    data: null
  };
  
  componentDidMount() {
    this.fetchData();
  }
  
  fetchData = async () => {
    this.setState({ loading: true });
    const data = await api.getUser(this.props.userId);
    this.setState({ data, loading: false });
  };
  
  render() {
    const { loading, data } = this.state;
    return loading ? <Spinner /> : <div>{data?.name}</div>;
  }
}
```

### ✅ Functional Component with Hooks

```typescript
function UserProfile({ userId }: Props) {
  const [loading, setLoading] = useState(false);
  const [data, setData] = useState<User | null>(null);
  
  useEffect(() => {
    async function fetchData() {
      setLoading(true);
      const userData = await api.getUser(userId);
      setData(userData);
      setLoading(false);
    }
    fetchData();
  }, [userId]);
  
  return loading ? <Spinner /> : <div>{data?.name}</div>;
}
```

## Lifecycle Method Mapping

| Class Lifecycle              | Hook Equivalent                           |
| ---------------------------- | ----------------------------------------- |
| `componentDidMount`          | `useEffect(() => {}, [])`                 |
| `componentDidUpdate`         | `useEffect(() => {}, [deps])`             |
| `componentWillUnmount`       | `useEffect(() => () => {}, [])`           |
| `shouldComponentUpdate`      | `React.memo()`                            |
| `getDerivedStateFromProps`   | `useState` + `useEffect`                  |

## Known False Negatives

- `createReactClass({...})` components are not covered; only classes.
- A superclass the file reaches through a helper (`class A extends withRouter(Component)`) is not followed.
