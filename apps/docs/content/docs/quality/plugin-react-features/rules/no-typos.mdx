no-typos rule

Detect common typos in React component properties and lifecycle methods. This rule is part of [`eslint-plugin-react-features`](https://www.npmjs.com/package/eslint-plugin-react-features).

## Rule Details

Detects misspellings of React's class-component API in a class component (a
class extending React's `Component` or `PureComponent`, by binding). React
calls lifecycles and reads statics by exact name, so a misspelt one silently
never runs.

Reported:

| Code                                         | Why                                          |
| -------------------------------------------- | -------------------------------------------- |
| `ComponentDidMount()`, `static PropTypes`    | React's name in another letter case          |
| `componenDidMount()`, `static defaulProps`   | a documented dropped-letter misspelling      |
| `Card.DefaultProps = {}` (Card is the class) | the same, assigned after the class           |
| `static componentDidMount()`                 | React calls lifecycles on the instance       |
| `getDerivedStateFromProps()` (not static)    | React calls it only as a static              |

Reading a static (`Card.propTypes`, `PropTypes.string`) is never reported, and
neither is any class that is not a React component.

## Examples

### ❌ Incorrect

```tsx
class MyComponent extends React.Component {
  // Typo in lifecycle
  componentDidUpate() {}  // Should be componentDidUpdate
  componentWillUnmout() {}  // Should be componentWillUnmount
  
  // Typo in static property
  static PropTypes = {};  // Should be propTypes (lowercase p)
}
```

### ✅ Correct

```tsx
class MyComponent extends React.Component {
  static propTypes = {};
  static getDerivedStateFromProps() {
    return null;
  }
  componentDidUpdate() {}
  componentWillUnmount() {}
}
```

## Known False Negatives

The rule reads class components only (a class extending React's `Component`
or `PureComponent`, by binding). Not detected:

- statics assigned to a function component (`Card.PropTypes = …`): whether a
  function is a component is not decided here;
- misspellings other than a different letter case and the listed dropped
  letters (`componentDidMoun`);
- a class extending a `Component` the file never imports or declares.
