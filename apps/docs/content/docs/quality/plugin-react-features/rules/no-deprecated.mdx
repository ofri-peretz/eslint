## Rule Details

Deprecated APIs will be removed in future React versions. Update to modern alternatives.

Reported, however the module is named (a named or renamed import, a default or namespace import, `require`, or the UMD globals `React` / `ReactDOM`):

- react-dom's `render`, `hydrate`, `unmountComponentAtNode` and `findDOMNode` (deprecated in React 18, removed in 19);
- react's `createClass` and `PropTypes` (removed in React 16);
- the lifecycle methods `componentWillMount`, `componentWillReceiveProps`, `componentWillUpdate` and their `UNSAFE_` forms, on a class that extends React's `Component` / `PureComponent` (a method, an arrow property or a quoted key).

Not reported: the same names on a local object or function, imported from another module, or declared on a class that is not a React component; a bare `render(…)` the file never imports.

## Examples

### ❌ Incorrect

```jsx
import React from 'react';

class MyComponent extends React.Component {
  componentWillMount() {
    // Deprecated
    this.loadData();
  }

  componentWillReceiveProps(nextProps) {
    // Deprecated
    this.setState({ data: nextProps.data });
  }
}
```

### ✅ Correct

```jsx
import React, { useEffect, useState } from 'react';

function MyComponent({ data }) {
  const [localData, setLocalData] = useState(data);

  useEffect(() => {
    loadData();
  }, []);

  useEffect(() => {
    setLocalData(data);
  }, [data]);
}
```
