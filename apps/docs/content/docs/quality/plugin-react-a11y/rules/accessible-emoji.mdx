Upstream's rule asked for emoji to be wrapped in a `span` with `role="img"` and an `aria-label`. jsx-a11y 6.10.2 deprecates it without naming a replacement. This rule is a no-op.

## Quick Summary

| Aspect         | Details                                          |
| :------------- | :----------------------------------------------- |
| **Status**     | Deprecated (`meta.deprecated: true`)             |
| **Reports**    | Nothing                                          |
| **In presets** | No preset enables it                             |
| **Options**    | An object, as upstream's schema; nothing is read |

## Why it exists

eslint-plugin-jsx-a11y 6.10.2 still exports this rule, deprecated. A config that registers this plugin under the `jsx-a11y` key and names `accessible-emoji`, or a `// eslint-disable-next-line jsx-a11y/accessible-emoji` comment, would otherwise stop ESLint with "Could not find rule". With this entry it loads and does nothing.

## Configuration

```javascript
// eslint.config.js
import reactA11y from 'eslint-plugin-react-a11y';

export default [
  {
    plugins: { 'jsx-a11y': reactA11y },
    rules: { 'jsx-a11y/accessible-emoji': 'off' },
  },
];
```
