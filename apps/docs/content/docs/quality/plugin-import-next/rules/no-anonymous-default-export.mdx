## Rule Details

A default-exported function or class without a name shows up as `default` (or nothing) in stack traces, profilers and React DevTools, and editors cannot auto-import it under a stable name. This rule reports a default export that is an anonymous value, read as `eslint-plugin-import` 2.32.0 reads it:

- an arrow function, also behind a TS wrapper (`(() => {}) as Handler`);
- an anonymous function expression or declaration (`export default function () {}`);
- an anonymous class expression or declaration (`export default class {}`).

- an array, a literal or template literal, an object, and a `new` expression, unless the matching option allows it (`allowArray`, `allowLiteral`, `allowObject`, `allowNew`).

A named function or class (also a named expression, `export default (function load() {})`) is fine, and so are identifiers, member references, interfaces and calls (`allowCallExpression` defaults to `true`).

**Default change (minor).** Before this release, with no options the rule reported only functions and classes, and `export default {}`, `[]`, a literal or `new Foo()` passed. They are now reported, as `import/no-anonymous-default-export` reports them. On receptron/mulmoclaude this moves 0 reports to 9, upstream's count. To keep the old behavior set `allowArray`, `allowLiteral`, `allowObject` and `allowNew` to `true`.

### ❌ Incorrect

```ts
export default () => {};
export default function () {}
export default class {}
```

### ✅ Correct

```ts
export default function load() {}
export default class Store {}
const handler = () => {};
export default handler;
const config = { retries: 3 };
export default config;
```

### eslint-plugin-import options

A config carried over from `import/no-anonymous-default-export` loads and means
the same. `allowAnonymousClass` and `allowAnonymousFunction` are its names for
`allowClassExpression` and `allowFunctionExpression`; a call is allowed unless
`allowCallExpression` is `false`.

```json
      },

        "type": "boolean",

      }

```

- `allowArrowFunction` (default `false`): accept an anonymous arrow function.
- `allowFunctionExpression` (default `false`): accept an anonymous function expression or declaration.
- `allowClassExpression` (default `false`): accept an anonymous class expression or declaration.

## When Not To Use It

When your tooling names default exports from the file name and anonymous ones do not hurt debugging.
