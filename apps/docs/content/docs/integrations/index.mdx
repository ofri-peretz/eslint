Interlace plugins work anywhere ESLint runs — including inside AI coding agents. We **do not ship our own MCP server**: the official [`@eslint/mcp`](https://www.npmjs.com/package/@eslint/mcp) auto-discovers every plugin from your `eslint.config.*`, so one local server exposes all Interlace rules (CWE-mapped metadata included) to your agent.
